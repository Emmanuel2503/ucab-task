# UCAB Tasks API

Proyecto de backend para la gestión de notas de texto, desarrollado con **NestJS** y **MongoDB** bajo el patrón de diseño Repositorio.

Este proyecto forma parte de la evaluación de la materia **Tópicos Especiales de Programación**.

## Requisitos Previos

Para poder ejecutar este proyecto en tu entorno local, asegúrate de tener instalado:

1.  **Node.js**: Versión 18 o superior (Recomendado LTS).
2.  **MongoDB**: Debe estar instalado y ejecutándose en el puerto por defecto `27017`.
3.  **Git**: Para clonar el repositorio.
4.  **Visual Studio Code**: Editor de código recomendado.

## Instalación y Configuración

Sigue estos pasos detallados para poner en marcha el servidor:

### 1. Clonar el repositorio
